Box-Sizing Comparison

This page demonstrates the difference between content-box (default) and border-box in CSS. Both boxes have the same declared width and padding, but their actual rendered sizes differ.

content-box
(Default)
Total size = width + padding + border

border-box
Total size includes padding and border

The purple box (content-box) grows larger because padding and border are added to its width and height. The teal box (border-box) keeps its total size consistent by including padding and border within the defined width and height.
