Responsive CSS Cheat Sheet

🎨 CSS Filters

filter: grayscale(100%) — Adjusts the visual appearance of elements like images. Common filters: blur(), sepia(), contrast(), brightness().

📱 Media Queries

@media (max-width: 768px) { ... } — Changes layout or style for specific screen sizes, enabling adaptive and responsive design.

💡 Responsive Design

Use flex, grid, and relative units like fr, %, vw, and vh to build layouts that automatically adapt to any device.

🔤 Responsive Typography

font-size: clamp(1rem, 3vw, 2rem); — Makes text scale smoothly between a minimum and maximum size for optimal readability.

⚙️ Transitions

transition: all 0.3s ease; — Smoothly animates changes in color, size, or position to create polished hover effects.

🎯 Grid Layout

grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); — Automatically fits and adjusts grid columns based on available space.
