Responsive Design Principles — Quick Summary

Fluid Layouts

Use relative units (%, vw, fr) so containers resize smoothly instead of using fixed pixel widths.

/* fluid container */
.container {
  width: 90%;
  max-width: 1200px;
  margin: 0 auto;
}

Flexible Media

Make images and media scale within their containers using max-width and object-fit to prevent overflow.

img, video {
  max-width:100%;
  height:auto;
  display:block;
  object-fit:cover;
}

Breakpoints

Use media queries to adjust layout at logical points (content-driven), not just device sizes.

@media (max-width: 900px) {
  .grid { grid-template-columns: repeat(2, 1fr); }
}

@media (max-width: 600px) {
  .grid { grid-template-columns: 1fr; }
}
